#+TITLE: Dotfiles

These dotfiles are tailored for my preferences running Omarchy.
Multiple aspects of these configs build on top on the omarchy defaults, hence these will not work well on any other distro without major changes.

** Contents

This repository contains:
- Package installation scripts, managed through =omarchy-packages/=
- Configuration files for =nix=, =hypr=, and other applications
- Personal shell scripts in =bin/=
- A unified =dotfiles= management script for syncing configs and installing packages

** Fresh Install

Run these once, in order, on a new machine. Steps 1 and 5 (=prepare= /
=finalize=) are only needed on a fresh install; steps 3 and 4 are the
day-to-day commands (see [[*Usage][Usage]]).

1. Clone this repository to =~/git/dotfiles=:
  #+begin_src bash
  git clone https://github.com/ThonyPrice/dotfiles.git ~/git/dotfiles
  cd ~/git/dotfiles
  #+end_src

2. Remove the Omarchy default configs we replace, so Stow can create clean
  symlinks instead of partially folding into existing directories:
  #+begin_src bash
  ./bin/dotfiles-prepare
  #+end_src

3. Install packages (this also installs =stow=, which the next step needs):
  #+begin_src bash
  ./bin/dotfiles packages install
  #+end_src

4. Sync configurations (symlinks every entry in =configs.list= via Stow):
  #+begin_src bash
  ./bin/dotfiles config sync
  #+end_src

5. Finalize — add =bin/= to =PATH= and install Doom Emacs:
  #+begin_src bash
  ./bin/dotfiles-finalize
  #+end_src

** Usage

After a fresh install, =dotfiles= is on =PATH= (via =dotfiles-finalize=, which
runs =stow-bin=), so it is executable from anywhere. Its purpose is to make it
*simple keeping dotfiles up to date with system configurations*:

#+begin_src bash
dotfiles config sync          # re-apply config symlinks (idempotent)
dotfiles config add <name>    # scaffold a new config to track
dotfiles packages install     # (re)install all packages
dotfiles packages add <name>  # scaffold a new package install script
#+end_src

Run =dotfiles --help= to see all available commands.

** Servers

The homelab boxes (=homelab-0=, =homelab-1=; repo =ThonyPrice/homelab=) get
the terminal half of these dotfiles, so a shell there feels like the laptop.
Both the =thony= and =agent= users get it.

- =servers.list= names the configs stowed there: a subset of =configs.list=.
- Omarchy's shell layer (aliases, functions, tool init) comes from the
  =omarchy-zsh= package on the laptop. That package builds it from
  [[https://github.com/omacom-io/omadots][omadots]], so servers clone omadots
  directly and link =~/.config/shell= to it. =.zshrc= loads whichever exists.
- =dotfiles server sync= pulls this repo and omadots and re-stows
  =servers.list=. A systemd timer runs it hourly for each user. The homelab
  repo's =ansible/roles/dotfiles= installs the tools, clones this repo to
  =~/git/dotfiles= and sets up the timer.
- Merging to =main= is the deploy: the boxes pick changes up within the hour.
- If a sync fails, the next login prints =dotfiles sync failed= with the
  journal command to look at.

Tools come from Ubuntu's packages, installed by the homelab role. A config
that needs a new tool needs a matching change there.

** Workaround: keep herdr out of systemd-oomd's reach

*Temporary. Follow up on 2026-12-01:* check
[[https://github.com/herdrdev/herdr/issues/6180][herdrdev/herdr#6180]] and remove
this once herdr ships a fix.

*Problem.* Omarchy lets systemd-oomd kill anything in =app.slice= when swap
passes 90% or memory pressure stays high (=/usr/lib/systemd/user/app.slice.d/10-oomd.conf=,
=/etc/systemd/oomd.conf.d/10-omarchy.conf=). oomd kills a whole cgroup at once.
herdr-core runs every pane in one transient unit, =hc-hold-<id>.service=,
started with =systemd-run= into =app.slice=. With several agent worktrees and
their Docker stacks running, the holder is always the largest candidate, so
one kill ended every terminal and agent at once. On 2026-11-24 this happened
three times in an hour (=journalctl --user | grep hc-hold= shows
=systemd-oomd killed N process(es) in this unit=).

*Workaround* (in =systemd/.config/systemd/user/=):
- =herdr.slice= is a slice with no =ManagedOOM*= policy, so oomd never picks it.
- =hc-hold-.service.d/slice.conf= is a prefix drop-in that applies to every
  =hc-hold-*.service= and sets =Slice=herdr.slice=.

Under real memory exhaustion the kernel OOM killer now kills a single process
(the biggest one), and the holder survives it because herdr sets
=OOMPolicy=continue= on it. The trade-off: without oomd's early kill, the
machine can stall for a while before the kernel steps in.

*Gotchas:*
- systemd ignores a drop-in directory that is itself a symlink. =~/.config/systemd/user/hc-hold-.service.d/=
  must be a real directory with only =slice.conf= linked inside it.
  =dotfiles config sync= creates systemd =*.d= directories before stowing so
  Stow can't fold them into a directory symlink.
- A holder only changes slice when it starts, so a holder that was already
  running when this was installed stays in =app.slice= until herdr restarts it.

Check it is active:

#+begin_src bash
systemctl --user list-units 'hc-hold-*' --no-legend | awk '{print $1}' \
  | xargs -r systemctl --user show -p Slice   # expect Slice=herdr.slice
oomctl | grep Path:                           # herdr.slice must not be listed
#+end_src

*Removing it* once herdr fixes #6180 (for example by running each terminal in
its own scope, or by offering a slice option):

#+begin_src bash
rm ~/git/dotfiles/systemd/.config/systemd/user/herdr.slice
rm -r ~/git/dotfiles/systemd/.config/systemd/user/hc-hold-.service.d
rm -r ~/.config/systemd/user/herdr.slice ~/.config/systemd/user/hc-hold-.service.d
systemctl --user daemon-reload
#+end_src

Not on the servers: =systemd= is not in =servers.list=.

** Updating Paper Desktop

Paper is built from our own PKGBUILD in =omarchy-packages/pkgbuilds/= (the AUR
=paper-desktop-bin= is stale), so =omarchy update= does not pick up new
releases, and the in-app "Check for updates..." can't install them either.
When the app reports a new version, re-run the install script; it always
builds the latest release:

#+begin_src bash
~/git/dotfiles/omarchy-packages/install-paper.sh
#+end_src

** Tmux Cheatsheet

Prefix key is =Ctrl+Space=. Press prefix, release, then press the command key.

*** Sessions (workspaces)

| Command                       | Description                  |
|-------------------------------+------------------------------|
| =tmux=                        | Start new session            |
| =tmux new -s name=            | Start new session with name  |
| =tmux ls=                     | List sessions                |
| =tmux attach -t name=         | Attach to session            |
| =tmux kill-session -t name=   | Kill session                 |
| =prefix + d=                  | Detach from session          |
| =prefix + $=                  | Rename session               |
| =prefix + s=                  | Switch session (interactive) |

*** Windows (tabs)

| Command        | Description           |
|----------------+-----------------------|
| =prefix + c=   | Create new window     |
| =prefix + ,=   | Rename window         |
| =prefix + n=   | Next window           |
| =prefix + p=   | Previous window       |
| =prefix + 1-9= | Go to window number   |
| =prefix + &=   | Kill window           |
| =Alt+L=        | Next window (custom)  |
| =Alt+H=        | Prev window (custom)  |

*** Panes (splits)

| Command             | Description                    |
|---------------------+--------------------------------|
| =prefix + "=        | Split horizontally             |
| =prefix + %=        | Split vertically               |
| =Ctrl + h/j/k/l=    | Navigate panes (vim-style)     |
| =prefix + x=        | Kill pane                      |
| =prefix + z=        | Toggle pane zoom (fullscreen)  |
| =prefix + !=        | Convert pane to window         |

*** Resize mode (custom)

| Command      | Description                          |
|--------------+--------------------------------------|
| =prefix + r= | Enter resize mode                    |
| =h/j/k/l=    | Resize pane left/down/up/right       |
| =Escape=     | Exit resize mode                     |

*** Copy mode (vim-style)

| Command      | Description              |
|--------------+--------------------------|
| =prefix + [= | Enter copy mode          |
| =v=          | Start selection          |
| =y=          | Copy selection           |
| =q=          | Exit copy mode           |

*** Other

| Command          | Description       |
|------------------+-------------------|
| =prefix + I=     | Install plugins   |
| =prefix + R=     | Reload config     |
| =prefix + ?=     | List keybindings  |
